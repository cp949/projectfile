# 최종 완료 체크리스트

roadmap-workflow 트랙-4에서 이 파일을 기준으로 점검한다. 작업 폴더에 복사하지 않고 결과는 `02-작업결과.md`에 적는다.

## 요구사항

- [ ] 계획서의 요구사항이 충족되었다.
- [ ] 모든 RD 완료 조건이 체크되었다.
- [ ] 범위 밖 변경이 없다.

## 리뷰

- [ ] DELTA 리뷰와 RD 통합 리뷰에 미해결 blocker·major가 없다.
- [ ] 작업 브랜치에 미커밋 변경이 남지 않았다.

## 검증

- [ ] DELTA별 검증 명령을 실행했다.
- [ ] `01-계획.md`의 전체 검증 명령을 실행했다.
- [ ] 실패한 검증이 남아 있지 않다.
- [ ] 테스트 정리를 DELTA마다, 그리고 작업 전체에 한 번 했다. 지운 테스트의 대체 검증이 기록돼 있다.

## 문서

- [ ] 공개 API나 동작을 바꿨으면 `packages/projectfile/README.md`를 맞췄다.
- [ ] 포맷이나 검사 규칙을 바꿨으면 `docs/format.md`를 맞췄다.
- [ ] 계획 대비 차이를 `02-작업결과.md`에 기록했다.
